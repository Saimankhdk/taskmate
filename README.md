# TaskMate (Flutter)

TaskMate is a productivity app built for a final semester capstone project.  
It combines team chat, task tracking, workspace groups, and calendar scheduling in one mobile app.

## Features

- Google/Firebase sign in
- Team and personal chats
- Workspace/group management
- To-do task planning
- Event scheduling and calendar view
- File and image sharing

## Tech Stack

- Flutter (Dart)
- Firebase Authentication
- Cloud Firestore
- Firebase Storage

## Run Locally

1. Install Flutter SDK.
2. Install dependencies:

```bash
flutter pub get
```

3. Run the app:

```bash
flutter run
```

## Notes

- Firebase setup is required before sign-in, storage, and cloud features will work.
- Main app logic is currently in `lib/main.dart` as part of the capstone build.
